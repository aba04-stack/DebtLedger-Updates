# Публикация обновления DebtLedger

## Перед публикацией

1. Соберите signed release APK проекта DebtLedger.
2. Убедитесь, что applicationId остаётся `com.aba04.debtledger`.
3. Увеличьте `versionCode`.
4. Подпишите APK тем же постоянным ключом, что используется установленной версией.
5. Рассчитайте SHA-256 именно файла APK.
6. Создайте GitHub Release с тегом, совпадающим с URL в `update.json`, например `v0.4.8`.
7. Загрузите asset с именем `DebtLedger-0.4.8.apk`.
8. Обновите `update.json`: versionCode, versionName, apkUrl и sha256.
9. Дождитесь успешного workflow `Validate update manifest`.

## Безопасность

Нельзя указывать фиктивный SHA-256 или APK другой подписи. Приложение дополнительно проверяет applicationId, versionCode и сертификат установленного приложения перед установкой.

Для новой версии сначала публикуется проверенный APK, затем обновляется manifest. Это предотвращает ситуацию, когда manifest уже обещает файл, которого ещё нет.
