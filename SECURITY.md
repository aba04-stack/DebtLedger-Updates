# Безопасность канала обновлений DebtLedger

В этот репозиторий нельзя добавлять приватные ключи подписи, пароли keystore или токены GitHub.

APK публикуются только как GitHub Release assets. Файл update.json содержит SHA-256 конкретного APK и HTTPS-адрес этого asset.

Приложение дополнительно проверяет applicationId, versionCode, SHA-256 и сертификат подписи APK относительно установленного приложения.

Если подпись не совпадает, APK не должен устанавливаться как обновление.
