# DebtLedger Updates

Официальный публичный канал обновлений для приложения DebtLedger.

## Что здесь находится

- `update.json` — manifest, который читает приложение.
- `.github/workflows/validate-update.yml` — автоматическая проверка manifest.
- `RELEASE.md` — инструкция безопасной публикации APK.

## Важно

Приложение проверяет HTTPS, SHA-256, applicationId, versionCode и сертификат подписи APK. Новый APK для автообновления должен быть подписан тем же постоянным ключом, что и установленная версия.

Текущий manifest указывает на стабильный путь релизного APK. Пока versionCode в manifest равен текущей версии приложения, обновление не предлагается.
